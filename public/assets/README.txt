Add your brand logo and profile photos in this folder. Profile photos are used automatically on the homepage and all maid directory cards.

Suggested files:
- logo.svg (or logo.png)
- hero-maid-1.jpg, hero-maid-2.jpg
- girlwithAE.png
- girlwithindianflag.png
- maidimage.png

`maidimage.png` is used for all maid profile cards. `girlwithAE.png` and `girlwithindianflag.png` are used only in the homepage hero/front section. Missing profile images fall back to the profile initial.
